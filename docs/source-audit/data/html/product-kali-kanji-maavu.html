Description

வறுத்த சிறுதானிய–பருப்பு மாவு

பாரம்பரிய சிறுதானியங்களும் பருப்பு வகைகளும் வறுத்து, கல் மில்லில் அரைக்கப்பட்ட மாவு. வறுத்து அரைப்பதால் ஆழமான சுவை கிடைக்கிறது. எந்தச் செயற்கைச் சேர்க்கையும் இல்லை.

சிறப்பம்சங்கள்

  • வறுத்த சிறுதானியங்களும் பருப்பு வகைகளும் மட்டுமே
  • நார்ச்சத்து நிறைந்த பாரம்பரிய காலை உணவு
  • சர்க்கரை, நிறமிகள், பாதுகாப்புப் பொருட்கள் எதுவும் சேர்க்கப்படவில்லை

தயாரிக்கும் முறை: தண்ணீர் சேர்த்துக் கலக்கிக் கஞ்சியாக அருந்தலாம்; கெட்டியாகக் கிளறினால் களியாகும். வெல்லம் அல்லது மோர் சேர்த்து உண்ணலாம்.
