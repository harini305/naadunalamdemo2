Description

ரத்தசாலி தன் பருக்கையின் சிவப்பு நிறத்தால் அந்தப் பெயரைப் பெற்ற பாரம்பரிய அரிசி வகை.

சிறப்பம்சங்கள்

  • கைக்குத்தல் முறையில் அரிசியாக்கப்பட்டது
  • தவிடு நீக்கப்படாத முழு அரிசி
  • இயற்கை விவசாய முறையில் விளைவிக்கப்பட்டது

சமைக்கும் முறை: இரண்டு மணி நேரம் ஊறவைத்து, மூன்று பங்கு நீர் விட்டு வேகவைக்கவும். சாதம், கஞ்சி, புட்டுக்கு ஏற்றது.
